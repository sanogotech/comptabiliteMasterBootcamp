# 1️⃣ Fondations Comptables Solides

🎯 Compétence à maîtriser :

* Plan Comptable
* Enregistrements journaux
* Lettrage
* Classement
* Cycle Clients / Fournisseurs / Caisse

SOFICOM AGRO achète :

* Matières premières : 12 000 000 FCFA
* Paie mensuelle : 6 000 000 FCFA
* Facturation clients : 22 000 000 FCFA

👉 Travaux à savoir faire :

* Écritures
* TVA
* Comptes à utiliser
* Lettrage Clients / Fournisseurs

### ⭐ Bonnes Pratiques

✔ Lettrer régulièrement

# 2️⃣ États Financiers (Objectif DAF et Audit)

🎯 Tu dois savoir produire :

* Bilan
* Compte de Résultat
* TAFIRE (SI présent dans ton pays)
* Notes annexes
* Tableau des flux de trésorerie

### 🧪 Exercice

À partir des écritures de SOFICOM :
👉 produire :

* Résultat
* Actif / Passif équilibré
* Fonds de roulement
* Besoin en fonds de roulement
* Trésorerie nette

### ⭐ Bonnes pratiques

✔ Toujours justifier chaque solde
✔ Vérifier cohérence bilancielle
✔ Documenter méthodes
✔ Versionner les livrables

---

# 3️⃣ Déclarations Fiscales & Sociales

🎯 Tu dois maîtriser :

* TVA
* IS / BIC
* Impôt sur salaire
* CNPS / Sécurité sociale
* Retenues à la source
* Patente / Contribution économique

### 🧪 Mini-Cas

SOFICOM fait 25M CA – TVA 18%
✔ Calcul TVA collectée
✔ TVA déductible
✔ Régularisation
✔ Déclaration mensuelle

### ⭐ Bonnes pratiques

✔ Tenir calendrier fiscal
✔ Archivage numérique + papier
✔ Toujours demander accusé de réception
✔ Anticiper trésorerie fiscale

---

# 4️⃣ Banque – Trésorerie – Rapprochement

🎯 Tu dois devenir experte de :

* Relevés bancaires
* Rapprochements
* Crédits / Découverts
* Gestion des chèques / virements

### 🧪 Mini-Cas

Relevé banque ≠ Comptabilité :

* Banque : 17 890 000
* Comptabilité : 19 100 000

👉 Savoir expliquer l’écart :

* chèques non encaissés
* virements en transit
* frais bancaires oubliés

### ⭐ Bonnes pratiques

✔ Faire rapprochement chaque mois
✔ Zéro écart inexpliqué
✔ Documenter les écarts justificatifs

---

# 8️⃣ 15 REX (retours d’expérience réalistes)

1️⃣ Erreur TVA → pénalité 3M
2️⃣ Mauvais lettrage → perte traçabilité
3️⃣ Pas de rapprochement → fraude banque découverte tard
4️⃣ Paie mal calculée → conflit social
5️⃣ Mauvaise gestion trésorerie → blocage activité
6️⃣ Déclaration tardive → majorations
7️⃣ Document non archivé → rejet fiscal
8️⃣ Balance non justifiée → Audit négatif
9️⃣ Mapping mal fait → reporting faux
🔟 Absence contrôle interne → détournement
11️⃣ Variation stock ignorée → résultat faussé
12️⃣ Aucun budget → dérive dépenses
13️⃣ Comptabilité manuelle → erreurs massives
14️⃣ Process non formalisé → dépendance personne
15️⃣ Absence tableau bord → pilotage aveugle

Pour chaque cas le remède =
**procédure + discipline + contrôle**
